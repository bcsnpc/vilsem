## What was added

Template formatVersion 2 (core 0.3, renderer 4.14+) adds six dimension/time slots, strict UTC date shaping and date/label formatters; window sum, lag and percent-of-total; bounded take; weighted links, two-to-six-level hierarchies, facet grouping and bounded repeat expansion. Links, hierarchy and facets carry source-row provenance through selection. Existing calculate/scalar/formatting contracts remain available. No caller callback, eval, Function constructor or arbitrary JavaScript was introduced. See spec-format.md for exact fields, null behavior, additive-measure constraints and limits.

## Category (c): Marimekko

A true Marimekko needs each category column's width proportional to its total and segments whose heights represent within-column shares. Native bar series use a series-level width on a category grid; they do not express independently data-scaled column widths. A treemap is not substituted because its packing does not preserve that Cartesian column/segment structure. ECharts custom series can draw those rectangles, but its renderItem algorithm is imperative and intentionally outside this JSON template format. Apache documents that callback contract in its [custom-series handbook](https://echarts.apache.org/handbook/en/how-to/custom-series/) and [custom series specification](https://github.com/apache/echarts-doc/blob/master/en/option/series/custom.md).

### Proposed sandboxed custom-series extension (design only)

- A spec references a versioned, content-addressed extension ID and a typed manifest (input fields, parameters, output primitives, deterministic limits). It never contains inline JavaScript, arbitrary URLs or unpinned package names. Built-in trusted extensions and explicitly installed third-party extensions remain distinguishable.
- Run extensions in a separate worker/process or capability-restricted WebAssembly runtime. They receive only selected normalized data columns, a bounded viewport, palette and explicit parameters. No host object, selection manager, credentials, model connector, file system, network, DOM or report definition is exposed. A plain Worker alone is **not** a security sandbox; a Node vm context is also insufficient.
- Return a validated display list of rectangle/path/text primitives with explicit clipping, coordinate units, accessibility labels and source row IDs. The trusted renderer performs drawing, tooltip dispatch, context menus and selection. No HTML, SVG script, event handlers, image URLs, callbacks or executable values are accepted in output.
- Enforce per-call CPU/fuel, memory, output primitive count, recursion, text length and deadline limits. Terminate on overrun; retain the last safe frame and expose a clear error. Abort stale requests on resize/filter changes. Deterministic inputs/outputs and seeded layout are required for SSR/Desktop parity and screenshot regression tests.
- Cache by extension content hash + core ABI + input schema, verify signatures/hashes before execution, and maintain an allowlist/revocation mechanism. Require explicit installation/permission for untrusted extensions and disclose which fields are passed. Public package publication must never silently grant data-exfiltration capabilities.
- Threat model: malicious package/source update, infinite loops, memory exhaustion, oversized paths/text, prototype pollution, cross-realm objects, stale async selection IDs, covert channels through output/logging and nondeterministic output. Test the boundary with adversarial payloads; fuzz manifest/display-list validation; do not rely on source-code string screening.
- Desktop/Service deployment must comply with the Power BI sandbox and certification restrictions. No runtime code download or privilege broadening is proposed. If a host cannot provide the required isolation, refuse the extension with an explicit unsupported-host state.

This extension is **not implemented**. Only Marimekko in this ten-visual exercise remains in category (c); its failure is preserved rather than hidden behind a static image or a different chart.

## Verification boundaries

A PNG or successful commit is not proof of Desktop rendering or host interaction parity. Preview is bounded to 200 grouped rows; Power BI may deliver a different filtered/reduced set. The Gantt has an explicit 16-row display sample. Window lag means previous returned observation; the radial example instead uses the model's Previous Month Revenue measure. Qualitative bullet bands are configured thresholds, not invented source measures. Negative graph/hierarchy weights are rejected. Live cloud Service/Fabric validation, exhaustive cross-highlight/bookmark/report-tooltip variants and certification are outside this expressiveness check.

Desktop also exposed an (a) background-token handling gap across all nine: the renderer forcibly replaced explicit template backgrounds with transparent, making light text unreadable on a white native page. Renderer 4.14.2 preserves explicit template backgroundColor; the examples now set `$theme.background`. Legacy composition transparency is unchanged and has a regression test.
