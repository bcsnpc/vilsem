# Vilsem v1.0.0-beta.3

This beta adds local Power BI report authoring and a broad visual-quality engineering update.

## Changes

- Connect a new Vilsem project to an existing local PBIP semantic model and save a separate Power BI report while preserving the source model.
- Restrict local-model projects to the supported local Power BI output; Fabric-connected projects retain cloud/web output choices.
- Improve formatting-pane organization, text and numeric formatting, pie/donut bounds, tooltip text handling, and chart selection/modifier behavior.
- Preserve binary report resources during updates and reject invalid insertion targets before model writes.
- Add cross-target QA scripts, architecture and visual inventories, regression coverage, and explicit issue/coverage records.
- Build the Power BI renderer before packaging so installers include the current renderer.

## Validation and limitations

- 625 unit tests pass; one known secondary-axis cross-filter test remains failing. Windows-checkout test harnesses now accept both LF and CRLF input.
- The preceding audit passed 40 app interaction/tooltip/animation checks and 82 compiled web/Fabric smoke checks. Native Service selection/clear passed for 16 selectable types; hosted Fabric checks cover selected interactions, not every state.
- Local Power BI currently supports 19 primitive types. The other 22 types, local slicers and saved drill/filter export remain unsupported. Existing-report insertion still has static-rendering limitations.
- Formatting/clipping acceptance, some visual semantics, dependency/lint findings, and full target parity remain open. See [regression status](../qa/regression-status.md) and [bug log](../qa/bug-log.md).
- Windows x64 installer; unsigned, consistent with earlier beta releases. Installer archive integrity, extracted application startup, preload availability, sign-in screen and Service Principal form passed. Interactive installation, upgrade and uninstall behavior have not been verified.

## Build

Install root, `ui`, and `pbiviz-semantica-renderer` dependencies, then run `npm run build` on Windows. This rebuilds Power BI, desktop, standalone web, and Fabric assets before creating the installer. The active packaging configuration is the `build` field in `package.json`; do not use the legacy `electron-builder.yml` configuration.
